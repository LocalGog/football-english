# Football English

Футбольна гра для вивчення англійської (Pre-A1 → A1). PWA: працює в браузері, встановлюється на телефон, після першого відкриття працює без інтернету. Без реєстрації, сервера, платних сервісів і реклами.

## Що вміє версія 0.7

- Перший запуск: ім'я, форма, одразу перший матч.
- 57 матчів у семи сезонах, 272 слова, 114 речень.
  - Сезони 1–3 (Football Starter, Young Player, Pro Academy) — слова й прості речення.
  - Сезон 4 · Football Champion — Present Simple і Present Continuous.
  - Сезон 5 · Pro League — Past Simple, was/were, did, 41 неправильне дієслово.
  - Сезон 6 · Champions League — will і going to.
  - Сезон 7 · World Cup — Present Perfect (already, just, yet, ever, never) і всі часи разом.
- Граматика: перед новою темою коротка картка з правилом українською та прикладами з футболу, далі в матчі вправи «встав пропущене» (121 вправа) і форми неправильних дієслів. Неправильні відповіді — типові помилки (goed, he play, will wins), тому інших правильних варіантів серед них немає. Помилки з граматики повертаються в тренувальних матчах.
- Завдання у форматі матчу: знайомство зі словом і вибір значення, «послухай і вибери», «як це англійською?», речення на слух, складання речення з блоків, діалог на полі. Фінал матчу — удар по воротах.
- Адаптивна складність із трьох ступенів. Новий гравець починає з найлегшого (3 варіанти, коротший матч). Після матчу з 90 % правильних відповідей ступінь зростає на один, нижче 60 % — знижується на один. На найвищому додаються зайвий блок у реченні та складання речення на слух.
- Аналіз помилок: гра запам'ятовує, у якому типі завдань слово дається гірше і з чим його плутають. Сплутані слова потрапляють у варіанти відповіді, а повторення ставить слово саме в слабкому типі завдання.
- Розділ Training: «Say it» (вимова), «Weak words» (матч зі слів, які не даються), «Review match».
- Вимова без розпізнавання мовлення: послухати зразок, сказати вголос, за бажанням записати себе й порівняти на слух. Запис не зберігається й не залишає телефон; без мікрофона тренування теж працює.
- Наступний сезон відкривається за знаннями: потрібно вивчити 60 % слів попередніх сезонів. До того PLAY NOW запускає тренувальні матчі зі слабких слів.
- Помилка нічого не забирає: питання повертається ще раз перед ударом.
- Озвучення системним голосом (Web Speech API): британська або американська вимова, три швидкості, повільний повтор. Без голосу на пристрої гра показує слово текстом.
- XP, рівні, футбольні статуси.
- Клуб: 22 картки справжніх футболістів (зірки та легенди). Кожен гол дає трансфер; щоб підписати гравця, треба прочитати звіт скаута англійською й відповісти на запитання (завдання Football Manager).
- Нагороди лише за навчання: форми за рівень, м'ячі за досягнення, стадіони за вивчені слова. Нічого випадкового й платного.
- Турнірна таблиця сезону: матч із голом — 3 очки, без гола — 1; матч можна переграти.
- 8 досягнень, серед них First Goal, First 20 Words, Perfect Match, Listening Master, Football Genius, 7 Days Champion (7 різних днів, пропуски не караються).
- Нижня навігація з шести розділів: Home, Play, My Club, Awards, Progress, Parents.
- Progress (для дитини): нові слова за тиждень, засвоєння тем, власний словник з озвученням.
- Parents (батьківський режим під PIN): вивчені слова, пройдені матчі, час занять із графіком за 7 і 30 днів, підсумки за тиждень і місяць, результати за типом завдань (читання, слухання, пригадування), складні слова з поясненням, засвоєні теми, рекомендований час на день, резервна копія, скидання прогресу з підтвердженням.
- Звіт за тиждень: кнопка «Надіслати звіт батькам» у Progress (і в Parents) відкриває меню «Поділитися» телефона з готовим текстом для Viber, Telegram чи SMS. Якщо меню недоступне, текст копіюється.
- Рекомендований час на день: гра не блокується, але після цілі дитина бачить пропозицію відпочити.
- Інтервальне повторення: 5 хв → 1 → 3 → 7 → 14 днів; пропущені слова повертаються в наступні матчі. Після сезону кнопка PLAY NOW запускає матч на повторення.
- Прогрес зберігається після кожної відповіді в IndexedDB (копія в localStorage).

## Запуск

Потрібен Node.js 20+.

```bash
npm install
npm run dev        # розробка: http://localhost:5173
npm test           # тести рушія, повторення, збереження
npm run build      # перевірка типів + збірка в dist/
npm run preview    # перегляд зібраної версії
```

Збірка — один `dist/index.html` (код і стилі всередині) плюс `manifest.webmanifest`, `sw.js` та іконки.

## Публікація на GitHub Pages (безкоштовно)

1. Створіть репозиторій на GitHub і завантажте в нього цей проєкт (гілка `main`).
2. У репозиторії: Settings → Pages → Source: **GitHub Actions**.
3. Файл `.github/workflows/deploy.yml` збере й опублікує застосунок після кожного push у `main`.
4. Адреса буде `https://<логін>.github.io/<репозиторій>/`.

Без Actions: виконайте `npm run build` і викладіть вміст `dist/` на будь-який статичний хостинг із HTTPS.

## Встановлення на телефон

- Android (Chrome): відкрийте адресу → меню ⋮ → «Установити додаток» / «Додати на головний екран».
- iPhone (Safari): «Поділитися» → «На початковий екран».

Офлайн-режим і встановлення працюють лише з HTTPS-адреси (GitHub Pages підходить).

Озвучення на Android потребує системного синтезу мовлення («Синтезатор мовлення Google», зазвичай уже встановлений) з англійською мовою.

## Контент

Увесь навчальний контент — у `src/content/*.json`, окремо від коду:

- `words.json` — слова (`id`, `english`, `ukrainian`, `category`, `difficulty`, `pronunciation`, `image`, `examples`, `audio`);
- `sentences.json` — речення для складання;
- `missions.json` — матчі: які слова й речення входять, рівень, нагорода, тривалість;
- `levels.json` — назви сезонів;
- `players.json` — картки справжніх футболістів. Зберігаються лише незмінні факти: країна, позиція, знаменитий номер, колір футболки збірної, відома риса. Клуб і поточний номер не вказуються навмисно, бо змінюються щосезону. Позиція, номер, колір і риса — це id слів зі словника; поля, крім позиції, можуть бути `null`;
- `club.json` — форми, м'ячі, стадіони, суперники в лізі (справжні клуби, результати в таблиці вигадані грою);
- `achievements.json` — досягнення: показник і ціль;
- `dialogues.json` — діалоги: репліки, варіанти відповіді, матч, до якого діалог належить;
- `categories.json` — назви тем українською для статистики;
- `grammar.json` — граматичні теми (правило, приклади з *виділенням*), вправи з пропуском (`before`, `answer`, `after`, `wrong`, `ukrainian`) і таблиця неправильних дієслів. Матч отримує граматику полем `grammar` у `missions.json`: тема, вправи, дієслова й форма (`past` або `participle`).

Щоб додати матч, допишіть слова й запис у `missions.json` (матчі мають іти за зростанням рівня). Завдання генеруються автоматично. `npm test` перевіряє посилання та унікальність слів і перекладів.

## Батьківський режим

Вкладка **Parents**. Під час першого входу створіть PIN із 4 цифр. Зберігається лише солоний хеш PIN-коду.

PIN, як і прогрес, зберігається лише на тому телефоні, де його створили. На телефоні дитини PIN має створити дорослий.

PIN захищає від випадкових змін на спільному телефоні, а не від зламу: усе зберігається в браузері. Якщо PIN забули, його можна скинути, ввівши слово «СКИНУТИ»; прогрес при цьому не змінюється, а дата скидання показується в батьківському режимі.

## Резервна копія прогресу

Прогрес зберігається тільки на пристрої. Очищення даних сайту в браузері його видаляє.

Parents → «Резервна копія».

- **Зберегти** — у завантаження телефона потрапляє файл `football-english-backup-РРРР-ММ-ДД.json`.
- **Відновити** — виберіть такий файл; гра покаже, чий це прогрес, і попросить підтвердити заміну.

Так само прогрес переноситься на інший телефон.

## Структура

```
src/content/   навчальний контент (JSON)
src/lib/       логіка без інтерфейсу: engine (побудова матчу), srs (повторення),
               progress (XP, рівні, відкриття сезонів, ступінь складності), report (звіт), club (нагороди, досягнення, ліга, скаут),
               stats (статистика), charts, pin, storage (IndexedDB), backup (копія),
               speech (озвучення), recorder (запис голосу)
src/screens/   Onboarding, Home, Play, Club, Awards, ProgressTab, Parent, Mission, Result, Scout, Speak
src/components/ Avatar (Jersey), Ball, BarChart, BackupPanel, ShareReport, PlayerCard, Pitch, BottomNav, WordImage,
               SettingsSheet, ErrorBoundary
public/        manifest, service worker, іконки
tests/         модульні тести
```

Залежності: React, lucide-react (ISC), Tailwind CSS, Vite, vite-plugin-singlefile, Vitest — усі з ліцензіями MIT або ISC.
